# Нагрузочный тест (k6)

Проверяет скорость под нагрузкой: веб-профиль по QR, публичный профиль через API, чтение книжки владельцем.
Claude не вызывается — тест бесплатный по AI.

```bash
brew install k6
k6 run tests/load/smart-contacts.js                 # smoke: 1 пользователь, 30 с
PROFILE=load k6 run tests/load/smart-contacts.js    # до 50 пользователей, ~5 мин
```

Чтение книжки — только с **тестовым** аккаунтом: `TEST_EMAIL=... TEST_PASSWORD=...`.

Пороги (PRD §6): профиль p95 < 1,5 с, запросы к БД p95 < 800 мс, ошибок < 1 %.
Перед `PROFILE=load` на бесплатном тарифе Supabase/Vercel учитывайте лимиты запросов.
