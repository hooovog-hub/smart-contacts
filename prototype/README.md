# Прототип

`smart-contacts-prototype.html` — кликабельный прототип (версия 21, ноябрь 2026). Открыть в браузере телефона.

Это **эталон UX и стиля**, а не production-код: данные демо, AI-помощник в прототипе работает через Claude только внутри claude.ai, иначе — простой поиск по ключевым словам.

Что смотреть: вкладки Знакомства · Контакты (Разделы / А–Я, «Ещё») · AI-помощник (голос, архив) · Мой профиль (бренды, членство, тарифы). Профиль человека: Давид Саргсян.
