# Журнал решений основателя

| Дата | Решение |
|---|---|
| 2026-11-01 | Продукт для любых бизнесменов, не только для одного клуба. Клубы — канал и платный сегмент. |
| 2026-11-01 | Free не показывает бизнесы; Pro показывает бренды, награды, членство, соцсети. |
| 2026-11-01 | Кнопка «Сохранить» в профиле — яркая, градиентная. |
| 2026-11-01 | Из профиля убраны: «Может помочь вам», статистика встреч/помощи/рекомендаций, «в Smart Contacts с …». |
| 2026-11-01 | Свёрнуты в профиле: «Сейчас ищет», «Контакты и соцсети», «Подробнее о себе», «Где пересекались», «Моя заметка». Остальное открыто. |
| 2026-11-01 | Бренды кликабельные, по тапу — окно со ссылками бренда. |
| 2026-11-02 | Стиль: тёмный минимализм (референсы Are.na, Serene), плавающая панель из иконок. |
| 2026-11-02 | AI-помощник: голос главный, запись прямо в строке ввода (как в Claude); задачи по разделам Бизнес/Личное/Друзья/Семья/Медицина/Дом и ремонт; 2 последних + «Архив» справа от заголовка. |
| 2026-11-02 | Рекомендации — на главной («Стоит написать сегодня»), не в AI. |
| 2026-11-02 | Книжка: чипы + «Ещё» сверху, разделы по 3 человека + «Все ›», переключатель «Разделы / А–Я». Порядок: Семья, Работа, Друзья, Ремонт, сообщества. |
| 2026-11-02 | Членство в организациях в профиле с подтверждением. Раздел сообщества (например, «Манташянц») собирается из членства. |
| 2026-11-02 | Тарифы: Free / Pro 5 000 ֏ / Business 25 000 ֏ (до 5 человек, +4 000 ֏ за каждого), год −2 месяца. |
| 2026-11-02 | Строим силами основателя и AI-агентов, без найма разработчика. |
