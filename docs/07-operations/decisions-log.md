# Журнал решений основателя

| Дата | Решение |
|---|---|
| 2026-11-01 | Продукт для любых бизнесменов, не только для одного клуба. Клубы — канал и платный сегмент. |
| 2026-11-01 | Free не показывает бизнесы; Pro показывает бренды, награды, членство, соцсети. |
| 2026-11-01 | Кнопка «Сохранить» в профиле — яркая, градиентная. |
| 2026-11-01 | Из профиля убраны: «Может помочь вам», статистика встреч/помощи/рекомендаций, «в Smart Contacts с …». |
| 2026-11-01 | Свёрнуты в профиле: «Сейчас ищет», «Контакты и соцсети», «Подробнее о себе», «Где пересекались», «Моя заметка». Остальное открыто. |
| 2026-11-01 | Бренды кликабельные, по тапу — окно со ссылками бренда. |
| 2026-11-02 | Стиль: тёмный минимализм (референсы Are.na, Serene), плавающая панель из иконок. |
| 2026-11-02 | AI-помощник: голос главный, запись прямо в строке ввода (как в Claude); задачи по разделам Бизнес/Личное/Друзья/Семья/Медицина/Дом и ремонт; 2 последних + «Архив» справа от заголовка. |
| 2026-11-02 | Рекомендации — на главной («Стоит написать сегодня»), не в AI. |
| 2026-11-02 | Книжка: чипы + «Ещё» сверху, разделы по 3 человека + «Все ›», переключатель «Разделы / А–Я». Порядок: Семья, Работа, Друзья, Ремонт, сообщества. |
| 2026-11-02 | Членство в организациях в профиле с подтверждением. Раздел сообщества (например, «Манташянц») собирается из членства. |
| 2026-11-02 | Тарифы: Free / Pro 5 000 ֏ / Business 25 000 ֏ (до 5 человек, +4 000 ֏ за каждого), год −2 месяца. |
| 2026-11-02 | Строим силами основателя и AI-агентов, без найма разработчика. |
| 2026-11-02 | Веб-профили делаем на Vercel Functions без Next.js: сборка Next.js на Vercel падала с ошибкой `export-detail.json` (известная проблема, не решена Vercel). |
| 2026-11-12 | Код попадает в `main` только через PR с зелёным CI; прямые коммиты запрещены (защита ветки). |
| 2026-11-12 | Wallet-карта: вариант «графит» с холста «Smart Contacts — Wallet-карта»; только для Pro/Business. |
| 2026-11-12 | Отчёты о сбоях храним в своём Supabase (`client_errors`), без сторонних сервисов вроде Sentry. |
| 2026-11-12 | Лимит Free — 5 задач AI в месяц — включён на сервере. |
| 2026-11-16 | Запуск: всем аккаунтам Pro бесплатно на 2 месяца от регистрации (`profiles.pro_until`, миграция 0008). Тариф меняет только сервер. После срока — через IAP (SC-060). |
| 2026-11-16 | Лимит AI на запуске: 10 сообщений помощнику в сутки для всех (считаются и уточнения). |
| 2026-11-16 | «Мой профиль» показывает ровно то, что видят другие; шкала заполненности с кнопками «+» — только пока профиль не заполнен. Про фото не напоминаем. |
| 2026-11-16 | Телефон — с выбором страны (по умолчанию Армения +374). |
| 2026-11-16 | «Вас ищут» (`features/needs-matching.md`): «Ищу» видно незнакомым только при согласии (по умолчанию — нет), согласие отзывается в любой момент. |
| 2026-11-16 | Незнакомому можно показать запрос и отправить оффер только при ≥ 1 общем знакомом (через одного человека, не через двух). |
| 2026-11-16 | Знакомы = записаны друг у друга по номеру (взаимно), или обмен QR, или общая комната. Одностороннее сохранение номера — не связь. |
| 2026-11-16 | Незнакомец видит карточку без телефона; телефоны открываются только после «Принять» оффер. |
| 2026-11-16 | Имя общего знакомого показываем всегда («Вас знакомит Карен»); у человека есть переключатель «Не показывать меня как общего знакомого». Проверить юристом (SC-070). |
| 2026-11-16 | Оффер = одно сообщение → «Принять / Нет»; своего чата в приложении нет. |
| 2026-11-16 | Отправлять офферы незнакомым — только Pro/Business (5 / 15 в неделю, цифры пересмотреть по данным); размещать «Ищу» и принимать офферы — бесплатно. |
