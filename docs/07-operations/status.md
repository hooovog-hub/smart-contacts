## Как продолжить работу
- Запуск приложения на iPhone: `npm_config_prefix="$HOME/.npm-global" npx expo start --tunnel` в `apps/mobile`, QR из терминала → Expo Go (аккаунт Expo: hooovo). Через Wi-Fi телефон до Mac не достаёт — нужен туннель.
- Перед любым коммитом: `npm run check` (то же, что CI).
- Симулятора iPhone нет: на Mac не установлен Xcode.
- Сборка в TestFlight: в `apps/mobile` → `npx eas-cli build --platform ios --profile production --auto-submit` (сертификаты и API-ключ App Store Connect хранятся в EAS).
- Вход через Apple, камера, фото, Wallet, SMS проверяем только в сборке TestFlight, не в Expo Go.
- Новые нативные модули → новая EAS-сборка и поднять `version` в `app.json` (runtimeVersion = appVersion), иначе OTA уронит старые сборки. Только JS → `eas update --branch production --environment production`.
- Серверные функции деплоятся через Supabase MCP (`deploy_edge_function`, с файлами `../_shared/*`); CLI Supabase не залогинен.
