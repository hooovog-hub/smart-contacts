## Как продолжить работу
- Запуск приложения на iPhone: `npm_config_prefix="$HOME/.npm-global" npx expo start --tunnel` в `apps/mobile`, QR из терминала → Expo Go (аккаунт Expo: hooovo). Через Wi-Fi телефон до Mac не достаёт — нужен туннель.
- Перед любым коммитом: `npm run check` (то же, что CI).
- Симулятора iPhone нет: на Mac не установлен Xcode.
