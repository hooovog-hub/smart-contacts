# ADR-0001: Мобильное приложение на Expo (React Native)

**Статус:** принято · **Дата:** 2026-11-02

## Контекст
Нужно iOS-приложение, позже Android; основатель работает без Mac и с AI-агентами.

## Решение
Expo + React Native + TypeScript, Expo Router, сборки в облаке EAS.

## Последствия
Один код на iOS и Android; сборка без Mac; огромная экосистема; AI-агенты хорошо пишут на TS/React. Минус: Wallet и некоторые нативные API требуют config plugins.
