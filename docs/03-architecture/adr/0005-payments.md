# ADR-0005: Оплата: Apple IAP для Pro, сайт и местный эквайринг для Business

**Статус:** принято · **Дата:** 2026-11-02

## Контекст
Apple требует IAP для цифровых подписок внутри iOS-приложения. Stripe в Армении недоступен.

## Решение
Pro — подписка через StoreKit (обёртка RevenueCat или expo-iap). Business — продажа компаниям через сайт и местный эквайринг (выбор провайдера — задача integrations-engineer), активация по вебхуку.

## Последствия
Соответствие правилам App Store; для B2B без комиссии Apple. Минус: две системы оплаты, нужна синхронизация `profiles.plan`.
