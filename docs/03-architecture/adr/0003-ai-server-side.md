# ADR-0003: AI только через сервер

**Статус:** принято · **Дата:** 2026-11-02

## Контекст
Ключ Claude API нельзя хранить в приложении; нужен контроль стоимости и данных.

## Решение
Все вызовы Claude — из Edge Function `ai-assistant`, которая сама читает контакты по JWT.

## Последствия
Ключ защищён, можно ограничивать лимиты по тарифу, минимизировать данные. Минус: +100–200 мс задержки.
