# ADR-0002: Бэкенд на Supabase

**Статус:** принято · **Дата:** 2026-11-02

## Контекст
Нужны БД, авторизация, файлы, серверные функции без своего сервера.

## Решение
Supabase (Postgres + RLS + Auth + Storage + Edge Functions).

## Последствия
Минимум инфраструктуры, RLS для приватности контактов, бесплатный старт. Минус: зависимость от провайдера (Postgres можно перенести).
