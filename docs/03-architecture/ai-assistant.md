# AI-помощник — устройство

## Задача модели
По тексту задачи пользователя найти в ЕГО контактах до 4 человек:
- `direct` — сам делает нужное;
- `indirect` — по работе знает нужных людей (дизайнер интерьеров → поставщики дверей).

Плюс: короткий ответ (1–2 предложения), раздел задачи, готовое сообщение каждому человеку от имени пользователя.

## Вход модели
1. Инструкция (system).
2. Каталог контактов — компактный JSON без телефонов: `{id, name, role, section, businesses?, helps?, seeks?, met?, myNote?}`.
3. История задачи (последние 6 сообщений).

При > 1 500 контактов — предварительный отбор: полнотекстовый поиск + эмбеддинги (P1) → в модель уходят 200 лучших кандидатов.

## Выход (JSON)
```json
{"category":"biz|personal|friends|family|med|home",
 "reply":"…",
 "people":[{"id":"<contact uuid>","kind":"direct|indirect","why":"…","ask":"…"}]}
```
Сервер отбрасывает `id`, которых нет в контактах пользователя.

## Модель и стоимость
Модель задаётся `ANTHROPIC_MODEL` (по умолчанию Sonnet-класс). Каталог кешируется prompt caching'ом между сообщениями одной задачи. Ориентир: < $0.01 за запрос при 300 контактах — проверять `data-analyst`.

## Качество (evals)
`supabase/functions/ai-assistant/evals.json` — набор запросов с ожидаемыми людьми на seed-данных. `ai-engineer` прогоняет после каждого изменения промпта.

## Приватность
Телефоны и email в модель не отправляются. Заметки пользователя отправляются (они полезны), это указано в политике конфиденциальности.
