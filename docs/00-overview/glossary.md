# Глоссарий

| Термин | Значение |
|---|---|
| Профиль | Публичная страница пользователя: роль, бренды, членство, награды, соцсети. |
| Контакт | Запись в книжке пользователя. Может быть связан с профилем (если человек в Smart Contacts) или быть просто номером из телефона. |
| Раздел (категория) | Группа контактов: Семья, Работа, Друзья, Ремонт, Медицина и т. д. Пользователь может добавлять свои. |
| Сообщество | Клуб, палата, ассоциация. Членство отображается в профиле; подтверждённые члены образуют раздел сообщества. |
| Комната | Пространство встречи с QR-входом. Все участники видят профили друг друга и сохраняют контакты. |
| Знакомство | Факт встречи: контакт + комната/место + дата + заметка. |
| «Вспомнить всех» | Режим после встречи: по очереди показать участников, отметить «говорили / нет», оставить заметку. |
| Задача (AI) | Запрос основателя к AI-помощнику («нужны двери»), с разделом, найденными людьми и статусом. |
| Напрямую / Может знать | Тип рекомендации AI: человек сам решает задачу / знает нужных людей. |
| Wallet-карта | Пропуск Apple Wallet (`.pkpass`) с QR на профиль. |
| Free / Pro / Business | Тарифы, см. `docs/06-business/pricing-and-plans.md`. |
