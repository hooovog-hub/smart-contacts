# Дизайн-система

Эталон: `prototype/smart-contacts-prototype.html`. Реализация токенов: `apps/mobile/src/theme/tokens.ts`.

## Принципы
Тёмный минимализм (чёрный фон, тёмно-серые карточки без рамок), один яркий акцент — градиент, системный шрифт iOS. Референсы: Are.na (структура), Serene (градиенты, плавающая панель).

## Типографика
SF Pro (системный). Заголовок экрана 24/700/-0.02em; имя в профиле 24/700; основной 15; вторичный 12.5–13; подписи секций 13/500 обычным регистром.

## Форма
Радиусы: карточки 18, крупные карточки 24, кнопки и чипы — капсула (999), нижние окна 28 сверху. Тени только у плавающих элементов (панель вкладок, док ввода, кнопка Сохранить).

## Компоненты
Плавающая панель вкладок (только иконки, активная — белый круг) · Чип раздела · Карточка контакта (строка) · Карточка бренда · Строка членства · Сворачиваемая секция · Док ввода AI с состоянием записи · Нижнее окно (sheet) · Пилюли статуса (PRO, Подтверждено, Напрямую, Может знать).
