# Контент-стратегия

## Рубрики
1. **Боль:** «Вы знаете, кто это — „Карен 2“ в вашем телефоне?»
2. **10 секунд:** показ QR → профиль → сохранено.
3. **AI решает:** голосом задача → кому звонить.
4. **Истории сообществ:** встреча клуба без бумажек.
5. **Советы нетворкинга.**

## Форматы
Reels 15–30 с, карусели, сторис с опросами. Языки: армянский и русский, английский для диаспоры.

## Частота
3 Reels + 2 карусели в неделю на этапе 2.
