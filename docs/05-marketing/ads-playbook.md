# Плейбук рекламы (Meta)

## Принцип
Маленькие бюджеты, быстрые тесты, решения по цифрам.

## Тест 1 — спрос (лист ожидания)
- Бюджет: $50–100, 5–7 дней, Армения, 25–55, интересы: предпринимательство, малый бизнес.
- 3 креатива × 2 текста.
- Цель: цена заявки. Ориентир решения — задаёт growth-lead до запуска.

## Правила
- Запуск и бюджет — только с подтверждения основателя.
- Итог каждой кампании — `marketing/ads/<кампания>.md`: настройки, цифры, вывод.
