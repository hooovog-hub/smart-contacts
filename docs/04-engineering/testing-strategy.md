# Стратегия тестирования

| Уровень | Инструмент | Что проверяем |
|---|---|---|
| Юнит | Jest | Утилиты, классификация, форматирование |
| Компоненты | React Native Testing Library | Ключевые экраны: книжка, профиль, док AI |
| БД | SQL-тесты (pgTAP) | RLS: чужой пользователь не видит чужие контакты, заметки, задачи |
| AI | evals.json | Качество подбора людей на seed-данных |
| Ручные | Чек-лист на iPhone | Ключевые сценарии перед каждым TestFlight |

## Ключевые сценарии (ручной чек-лист)
1. Регистрация → профиль → QR → открыть QR другим телефоном без приложения.
2. Импорт контактов → разделы → А–Я → поиск.
3. Создать комнату → войти гостем → «Вспомнить всех».
4. Голосом «нужны двери» → люди → «Решено».
5. Free vs Pro отображение профиля.
