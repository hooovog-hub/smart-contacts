# AI-помощник

**ID:** SC-040 · **Приоритет:** P0 · **Статус:** утверждено основателем (по прототипу v21)

Прототип: `prototype/smart-contacts-prototype.html`

## Экран списка
- Заголовок «AI-помощник», подзаголовок «Скажите задачу — найду, кому позвонить».
- Чипы разделов задач: Все · Бизнес · Личное · Друзья · Семья · Медицина · Дом и ремонт (показываются только непустые).
- Секция «Последние» — 2 самые свежие задачи. Справа от заголовка ссылка «Архив · N ⌄», по тапу остальные задачи появляются ниже, ссылка становится «Скрыть архив ⌃».
- Карточка задачи: название, раздел, аватары найденных людей, «N человека · вчера» или «✓ Помог(ла) <имя>».
- Рекомендаций на этом экране нет (они на главной).

## Строка ввода (док)
Закреплена над нижней панелью, затемнение за ней, контур и тень. Справа большая градиентная кнопка микрофона. Когда пользователь печатает — кнопка меняется на белую «отправить».

## Голосовой ввод
Тап по микрофону: строка расширяется, оранжевая светящаяся обводка, текст появляется по мере речи (распознавание на устройстве, iOS Speech), снизу: ✕ отменить · волна · ■ остановить · ↑ отправить. Без отдельного окна.

## Экран задачи
Назад, название, «<раздел> · в работе · вчера». Кнопка «✓ Отметить решённой» → «Кто помог?» (аватары предложенных + «Решил сам»). Переписка: сообщения пользователя справа; ответ AI — текст + карточки людей: аватар, имя, метка «Напрямую» / «Может знать», причина, готовое сообщение, кнопки «Позвонить», «Копировать сообщение», «Профиль». Строка ввода для уточнений.

## Логика
См. `docs/03-architecture/ai-assistant.md`. Раздел задачи определяет AI (поле `category`).

## Лимиты
Free — 5 задач в месяц. Pro/Business — без лимита (fair use).

## Критерии приёмки
- Дано в контактах производитель дверей и дизайнер интерьеров, когда запрос «нужны двери для офиса», тогда первый — «Напрямую», второй — «Может знать».
- AI никогда не возвращает людей, которых нет в контактах пользователя.
