# Удаление аккаунта

**ID:** SC-072 · **Приоритет:** P0 · **Статус:** реализовано (ждёт проверки на iPhone) · **Автор:** оркестратор

## Проблема
Apple отклоняет приложения, где можно создать аккаунт, но нельзя удалить его внутри приложения (App Review 5.1.1(v)). Кроме того, это право пользователя на его данные.

## Сценарии
1. «Профиль» → внизу «Удалить аккаунт» → окно «Удалить аккаунт?» с перечнем, что пропадёт → «Удалить навсегда».
   Если вход был через Apple — ещё окно Apple с Face ID (подтверждает владельца и даёт код для отзыва токенов).
2. Аккаунт и все данные удаляются на сервере, приложение возвращается на экран входа.
3. «Отмена» (в любом из окон) — ничего не происходит.
4. Повтор после потерянного ответа сервера: если аккаунта уже нет, приложение просто выходит на экран входа.

## Экраны и состояния
| Экран | Состояния |
|---|---|
| Профиль, кнопка «Удалить аккаунт» | обычное / «Удаляем…» (кнопка неактивна) / ошибка — окно «Не получилось удалить», можно повторить |

## Данные
Edge Function `delete-account` (POST, JWT пользователя, тело `{ "confirm": "DELETE_MY_ACCOUNT", "appleAuthorizationCode"?: "…" }`):
1. Для пользователей Apple: обменивает свежий код на токен и отзывает его (`appleid.apple.com/auth/revoke`, Apple TN3194). Нужны секреты `APPLE_TEAM_ID`, `APPLE_KEY_ID`, `APPLE_PRIVATE_KEY` (.p8). Если секретов нет или Apple недоступен — удаление всё равно идёт, сбой пишется в отчёт.
2. Удаляет файлы `<user_id>/…` (рекурсивно) во всех бакетах Storage (сейчас бакетов нет — на будущее для фото).
3. Удаляет пользователя `auth.users` → каскадом `profiles` и всё, что на него ссылается: бренды, членство, награды, рекомендации, разделы, контакты, комнаты, отметки встреч, задачи AI, `ai_usage`, команды.
После этого удаляются строки `client_errors` пользователя (у таблицы нет внешнего ключа).
У чужих книжек `contacts.linked_profile_id` становится пустым — сам контакт у другого человека остаётся (это его данные).

## Правила и ограничения
- id пользователя берётся только из JWT, никогда из тела запроса.
- Удаление необратимо, корзины нет.
- Публичная страница может ещё до ~6 минут отдаваться из кэша CDN.
- Handle сразу становится свободным — защита старых QR в SC-073.
- В логах нет персональных данных.

## Критерии приёмки
- **Дано** вошедший пользователь, **когда** он подтверждает удаление, **тогда** его строки нет в `auth.users` и `profiles`, контакты и задачи удалены, приложение показывает экран входа.
- **Дано** удалённый аккаунт, **когда** открыть его `/<handle>` или QR, **тогда** профиль не находится.
- **Дано** запрос без фразы подтверждения или без JWT, **тогда** функция отвечает 400 / 401 и ничего не удаляет.

## Вне рамок
- Выгрузка данных перед удалением.
