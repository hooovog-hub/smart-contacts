# Вход

**ID:** SC-011 · **Приоритет:** P0 · **Статус:** Apple ID реализован (ждёт настройки Supabase и проверки на iPhone); телефон — не начат · **Автор:** оркестратор

## Проблема
Пароли неудобны и рискованны. На iPhone самый быстрый вход — «Продолжить с Apple»: одно касание, Face ID.

## Сценарии
1. Экран входа → «Продолжить с Apple» → системное окно Apple → Face ID → в приложении.
2. Первый вход: Apple передаёт имя → оно уже заполнено на экране создания профиля.
3. Повторный вход: сразу на главную.
4. Отмена в окне Apple — остаёмся на экране входа без ошибки.
5. Запасной путь: почта и пароль (как раньше).

## Экраны и состояния
| Экран | Состояния |
|---|---|
| Вход | кнопка Apple (только iOS, где доступно) / загрузка / ошибка «Не получилось войти через Apple» |
| Создание профиля | имя заполнено из Apple, если пришло |

## Данные
`supabase.auth.signInWithIdToken({ provider: "apple", token, nonce })`. Имя — в `auth.users.raw_user_meta_data.full_name`. Профиль создаётся как раньше, на онбординге.

## Правила и ограничения
- Nonce: Apple получает SHA-256 одноразового значения, Supabase проверяет исходное — защита от повторного использования токена.
- Если пользователь скрыл почту, Apple даёт адрес вида `…@privaterelay.appleid.com` — это нормально.

## Настройка (один раз)
1. **Supabase → Authentication → Sign In / Providers → Apple → Enable.** В поле Client IDs: `am.smartcontacts.app,host.exp.Exponent` (второе — для проверки в Expo Go; убрать перед запуском). Secret Key для входа из приложения не нужен.
2. **Ключ для отзыва токенов (нужен для удаления аккаунта):** Apple Developer → Keys → «+» → Sign in with Apple → Configure: App ID `am.smartcontacts.app` → скачать `.p8`. В Supabase → Edge Functions → Secrets: `APPLE_TEAM_ID`, `APPLE_KEY_ID`, `APPLE_PRIVATE_KEY` (содержимое .p8). В git не класть.
3. **Apple Developer:** у App ID `am.smartcontacts.app` включается Sign in with Apple — EAS сделает это сам при первой сборке (`ios.usesAppleSignIn` в `app.json`).

## Критерии приёмки
- **Дано** iPhone с Apple ID, **когда** нажать «Продолжить с Apple» и подтвердить Face ID, **тогда** открывается создание профиля с именем (первый раз) или главная (повторно).
- **Дано** открытое окно Apple, **когда** нажать «Отменить», **тогда** сообщения об ошибке нет.

## Вне рамок
- Вход по номеру телефона (нужен SMS-провайдер, платно) — решение основателя.
