# Контактная книжка

**ID:** SC-020 · **Приоритет:** P0 · **Статус:** утверждено основателем (по прототипу v21)

Прототип: `prototype/smart-contacts-prototype.html`

## Сценарии
1. Первый запуск: запрос доступа к контактам с объяснением → импорт → AI раскладывает по разделам → экран «Готово: N из M разобраны» → разбор «Не разобрано» по одному (тап по разделу или «в архив»).
2. Ежедневно: поиск, чипы, разделы, А–Я.

## Экран
- Заголовок «Контакты», подзаголовок «N человек», справа переключатель «Разделы | А–Я».
- Поиск: имя, роль, «кто чинит двери».
- Режим «Разделы»: строка чипов (Все + разделы с количеством; порядок: Семья, Работа, Друзья, Ремонт, сообщества, затем по убыванию), справа закреплена «Ещё ⌄» → нижнее окно-сетка всех разделов (иконка, название, количество) + «Изменить».
  - Без выбранного раздела: секции разделов, в каждой 3 человека по алфавиту и «Все ›».
  - Выбран раздел: «‹ <Раздел> N» и полный список.
- Режим «А–Я»: буквенные заголовки, под именем «роль · раздел», справа указатель букв (активные подсвечены).

## Разделы по умолчанию
Семья, Работа, Друзья, Ремонт, Медицина, Финансы и право, Путешествия, Дом и быт, Авто, Рестораны, Образование, Красота. Раздел сообщества появляется автоматически из подтверждённого членства (например, «Манташянц»). Пользователь может создавать свои и менять порядок.

## Временные контакты
Такси, курьер, трансфер — помечаются временными и уходят в архив через 30 дней (настраивается).

## Критерии приёмки
- Дано 500 контактов, когда импорт завершён, тогда ≥ 70% разложены по разделам автоматически.
- Дано режим А–Я, когда тап по букве «К», тогда список прокручивается к первому контакту на «К».
