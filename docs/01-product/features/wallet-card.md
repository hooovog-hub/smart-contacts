# Wallet-карта

**ID:** SC-050 · **Приоритет:** P1 · **Статус:** код готов, ждёт сертификат Apple (`docs/04-engineering/wallet-setup.md`)

Дизайн: холст «Smart Contacts — Wallet-карта» в claude.ai, вариант «Ближайший вариант для Apple Wallet» (графит).

## Сценарий
«Добавить в Apple Wallet» в «Мой QR» → сервер генерирует `.pkpass` (тип generic) → карта в Wallet: имя, роль, компания, QR на `/<handle>`. Изменения профиля обновляют карту через Wallet web service (push).

## Как устроено
Приложение → `POST /api/wallet` с сессией → подписанная ссылка на 5 минут → Safari открывает `GET /api/wallet?t=…` → `.pkpass`. Free видит кнопку с пометкой Pro.

## Ограничения
- Двойное нажатие боковой кнопки открывает Wallet с банковской картой сверху; визитка — в списке под ней. Ставить визитку «по двойному нажатию» iOS не даёт (только платёжные карты).
- Передача касанием телефонов (NFC) недоступна для визиток: NFC в пропусках требует специального разрешения Apple. Используем QR и AirDrop.
- Нужен Apple Developer Program и Pass Type ID (см. ADR-0004).

## Критерии приёмки
- Дано Pro-пользователь, когда «Добавить в Wallet», тогда карта добавляется и QR открывает его профиль.
- Дано изменение роли, тогда карта обновляется в течение 5 минут. → SC-051
