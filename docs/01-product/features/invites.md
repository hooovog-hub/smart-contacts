# Приглашения друзей

**ID:** SC-081 · **Приоритет:** P0 · **Статус:** реализовано в 0.2.0 (ждёт проверки на iPhone) · **Автор:** оркестратор

## Решения основателя (2026-11-16)
- **10 друзей с заполненным профилем = +1 месяц Pro** пригласившему.
- Приглашение засчитывается **по коду при регистрации**: подставляется сам, если приложение открыто по ссылке, иначе вводится вручную.
- Массовая автоматическая рассылка по всем контактам — нет (iOS не позволяет, WhatsApp банит, Apple отклоняет). Вместо неё — выбор людей и одно SMS всем выбранным.

## Сценарии
1. «Профиль» → «Пригласить» (или карточка на «Сегодня») → экран с прогрессом «N из 10», личной ссылкой `smart-contacts.vercel.app/i/<код>`, «Поделиться» (WhatsApp, Telegram, почта…) и списком контактов с галочками → «Отправить SMS выбранным» (до 50 за раз, открывается системное SMS с готовым текстом).
2. Этот же экран открывается сразу после импорта контактов.
3. Друг открывает ссылку → страница «<Имя> приглашает вас» с кнопкой установки (`INVITE_INSTALL_URL` в Vercel, пока TestFlight) и кодом → при создании профиля поле «Код пригласившего» заполнено (deep link `smartcontacts://i/<код>`) или вводится.

## Данные и правила
- `profiles.invite_code` — случайные 8 символов, публичный (нужен, чтобы открыть ссылку). Кто кого пригласил — только в `profile_invites` (видит сам приглашённый; пригласивший — только счётчики через `my_invite_stats()`).
- Связь ставится один раз, сразу после создания профиля. Если профиль уже создан — засчитать нельзя.
- «Заполненный профиль» для зачёта: имя, «чем занимаетесь», телефон и («О себе» или бренд). Зачёт и бонус — триггеры в базе (`private.count_invite`), идемпотентно (`invite_rewards`); тариф Business не понижается; бессрочный Pro — бонус фиксируется без изменений.
- Миграция `0009_profile_today_invites.sql` (прошла security-review).

## Открытые вопросы (до SC-060)
- Верхний предел бонусов в год и более строгий зачёт (подтверждённый телефон, N дней активности) — от накрутки.
- Как бонусный месяц сочетается с оплаченной подпиской IAP.
