# marketing/ — рабочая папка маркетинговых агентов

| Папка | Кто пишет | Что |
|---|---|---|
| `content/` | content-strategist, content-creator | Контент-планы, тексты, сценарии |
| `ads/` | ads-manager | Кампании: настройки, результаты, выводы |
| `campaigns/` | marketing-lead | Сводные планы кампаний |
| `partners/` | community-manager | Клубы, палаты, конференции, предложения |
| `assets/` | brand-designer | Логотипы, креативы (без исходников > 10 МБ) |

Стратегия — в `docs/05-marketing/`. Здесь — рабочие материалы.
